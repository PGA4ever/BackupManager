================================================================================
💡 USAGE EXAMPLES
================================================================================

HOW USERS UPDATE:
  1. User runs app
  2. Goes to Settings tab
  3. Clicks "Check for Updates"
  4. App checks GitHub for new versions
  5. If update found:
     - Shows dialog: "Update available!"
     - Downloads new version
     - Installs automatically
     - Restarts app with new version
  6. If no update:
     - Shows: "You are using the latest version"

HOW YOU RELEASE UPDATES:
  1. Update version in BackupManager.csproj
  2. Build: dotnet publish -c Release
  3. Commit: git commit -m "Version 1.0.1"
  4. Push: git push
  5. Create Release on GitHub (tag: v1.0.1)
  6. Users see update and can install!

❓ QUICK TROUBLESHOOTING
================================================================================

Problem: "Check for Updates button doesn't appear"
Solution: Run dotnet build, restart Visual Studio, check MainWindow.xaml

Problem: "GitHub setup fails"
Solution: Verify GitHub account exists, run .\setup-github.ps1

Problem: "Updates not detected on GitHub"
Solution: Verify repo is PUBLIC, release tag is v1.x.x format

Problem: "Application crashes on update"
Solution: Test build locally first, include all DLLs in release
